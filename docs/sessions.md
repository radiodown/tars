# 세션 사용

세션은 이전 대화와 작업 문맥을 이어가는 단위입니다. AI가 응답을 마쳐도 같은 세션에서 다음 메시지를 보내면 기존 문맥을 이어갑니다.

## 새 세션

대화창에서 **새 세션**을 누르거나, 선택된 세션 없이 첫 메시지를 보냅니다. 새로운 문맥으로 시작하며 이전 세션의 대화 기록을 자동으로 가져오지 않습니다. 같은 AI에게 여러 세션을 만들 수 있습니다.

프로젝트는 새 세션을 시작하기 전에 선택합니다. 기존 세션의 프로젝트를 바꾸려면 새 세션을 만듭니다. 공용 지침과 해당 프로젝트의 자료는 새 세션에도 적용됩니다.

## 계속 대화하기

열려 있는 세션에서 후속 메시지를 보내면 같은 Codex thread 또는 Claude session을 재개합니다. 대화 문맥은 유지하고, 각 처리의 지시·상태·로그·결과는 별도 실행 기록으로 보관합니다.

실행 중에는 추가 지시를 보내거나 **중지**할 수 있습니다. 다른 세션이나 자동 작업에서 해당 AI를 사용 중이면 메시지는 선택한 세션의 대기열에 들어갑니다. 처리 순서가 와도 다른 세션으로 이동하지 않습니다.

## 닫기와 재개

**세션 닫기**, 대화 패널 닫기 또는 페이지를 떠나는 동작은 대화 기록을 삭제하지 않습니다. 창을 다시 열었을 때는 이전 세션을 자동 선택하지 않습니다. **세션** 목록이나 대화창의 **세션 선택**에서 이전 세션을 명시적으로 열어 재개합니다. 특정 세션 링크로 들어가는 것도 해당 세션을 선택하는 동작입니다.

TARS는 서버에서 실행하므로 브라우저나 패널을 닫아도 진행 중인 실행은 계속됩니다. 실행까지 멈추려면 **중지**를 사용합니다. 서버 재시작으로 중단된 실행은 자동으로 다시 실행하지 않으며, 사용자가 세션을 열고 후속 메시지를 보내면 보존된 문맥에서 이어갑니다.

재개할 때 모델 호출은 메시지를 보낼 때 일어납니다. 세션 목록을 열거나 이전 기록을 읽는 것만으로 AI를 실행하지 않습니다.

## 문맥 보존과 재개 오류

모델·추론 수준 또는 지침이 바뀌어도 기존 세션을 선택하면 저장된 제공사 대화를 재개하고 현재 설정을 적용합니다. 실패·중단된 턴 뒤에도 저장된 제공사 ID가 있으면 같은 세션을 사용합니다. 이전 입력을 자동 재전송하지는 않습니다.

제공사·계정·프로젝트·작업 경로는 세션의 재개 범위입니다. 다른 제공사나 계정으로 바꾼 경우 원래 설정으로 돌아가거나 새 세션을 만듭니다. 제공사 기록이 사라졌거나 재개 요청이 거절되면 오류를 표시합니다. 오류를 숨기고 새 제공사 문맥으로 바꾸지 않습니다.

세션의 기록 보존과 모델이 한 번에 참조하는 문맥의 크기는 다릅니다. 제공사의 문맥 한도와 압축 정책은 그대로 적용됩니다.

## 기록 확인

**세션** 목록은 문맥을 공유하는 세션별로 표시합니다. 각 응답의 **실행 기록**에서 명령·도구 출력과 상태를 확인합니다. **전체 실행 기록**에서는 업무·작업별 수행·검토·보고도 확인할 수 있습니다.

이전 버전의 기록은 제공사 대화 ID를 우선해 세션으로 묶습니다. 같은 AI의 기록이라도 제공사 대화 ID가 다르면 별도 세션으로 보존합니다.
