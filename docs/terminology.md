# TARS 용어

**세션은 같은 대화 이력과 문맥(context)을 공유하며 대화를 이어가는 단위입니다.** Codex CLI나 확장 프로그램에서 한 대화를 계속 이어가고, 종료 후 resume으로 그 대화를 다시 여는 개념을 따릅니다.

| 용어 | 정의 |
| --- | --- |
| 프로젝트 | 업무가 대상으로 삼는 소스와 작업 경로 |
| 부서 | 담당 영역과 구성원을 묶는 조직 단위 |
| 구성원 | 이름·역할·제공사·모델·지침을 가진 AI 담당자. CEO·팀장·팀원 역할을 가짐 |
| 대화 | 사용자와 AI가 메시지를 주고받는 행위와 내용 |
| 세션 | 하나의 AI와 같은 대화 문맥을 유지하는 지속 단위. 여러 턴과 실행을 포함함 |
| 턴 | 사용자 입력을 받아 AI가 처리하고 응답하는 한 차례. 도구 사용과 질문·승인 대기가 포함될 수 있음 |
| 실행 | TARS가 AI 처리를 시작하고 종료할 때까지 관리하는 단위. 상태·시간 제한·로그·결과를 가짐 |
| 실행 기록 | 실행에서 받은 지시, 도구·명령 출력, 결과와 상태 변경의 기록 |
| 업무 | 수행할 목표와 범위를 정해 CEO·팀장이 등록한 일 |
| 작업 | 업무에 속하는 개별 수행 단위. 담당자·완료 기준·선행 작업 등을 가짐 |
| 결과 | 작업을 수행해 제출한 내용과 산출물·검증 근거 |
| 검토 | 제출된 결과가 완료 기준을 만족하는지 확인하는 과정 |
| 승인 | 사용자가 협의 범위나 최종 결과를 확인하는 결정. 명령·파일 변경에 대한 실행 승인과는 대상을 구분해 표시함 |

## 관계

AI 한 명에게 여러 세션이 있을 수 있습니다. 각 세션의 대화 이력은 독립적이며, 같은 AI라는 이유로 다른 세션의 대화를 자동으로 합치지 않습니다. 조직·프로젝트 지침과 업무 자료는 별도로 공유될 수 있습니다.

한 세션에는 여러 턴과 실행 기록이 쌓입니다. 실행 중 추가 지시를 받는 방식에 따라 한 실행 안에 여러 입력·응답이 포함될 수도 있으므로 턴과 실행을 항상 같은 개수로 계산하지 않습니다.

하나의 업무에는 여러 작업이 연결될 수 있고, 작업을 구현·검토·보완하는 과정에는 여러 실행과 여러 담당자의 세션이 참여할 수 있습니다. 메시지 전송 자체가 업무 등록을 의미하지 않습니다.

## 종료와 완료

- **응답 종료**: 해당 응답을 마쳤습니다. 세션의 문맥은 다음 대화에서 이어집니다.
- **실행 중지**: 현재 처리를 멈춥니다. 세션 기록은 남습니다.
- **세션 닫기**: 화면에서 세션을 떠납니다. 이후 이어가려면 해당 세션을 선택해 재개합니다.
- **작업 완료**: 작업 결과가 검토를 통과했습니다.
- **업무 완료**: 필요한 수행·검토·보고를 마치고 사용자가 최종 결과를 확인했습니다.

AI 실행이 끝났다는 사실만으로 작업이나 업무를 완료로 표시하지 않습니다.
